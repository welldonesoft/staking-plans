# L.P.28 Staking Plan

## Overview

A target-based staking plan with a 28-step structure. Designed to provide a systematic approach to achieving profit targets with controlled stake escalation across up to 28 bets per cycle.

## How It Works

1. Divide the profit target across up to 28 steps
2. Each step has a calculated stake based on remaining target and current position
3. Wins reduce the remaining target; losses are absorbed into future stakes
4. The 28-step structure provides a defined cycle length

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `target` | number | 100 | Total profit target |
| `steps` | number | 28 | Number of steps in the plan |

## Risk Assessment

- **Risk Level:** Medium
- **Max Drawdown:** Spread across 28 steps — moderate
- **Recommended Bankroll:** 10× target
- **Ruin Risk:** Medium-low — the 28-step limit provides a natural stop

## When to Use

- You prefer structured, time-bound staking cycles
- Your system has consistent results over 28-bet periods
- You want a plan with a defined endpoint

## When to Avoid

- Very inconsistent results
- You prefer open-ended plans

## Betfair Exchange Notes

- Works for both back and lay
- For lay, structure the target around liability targets
